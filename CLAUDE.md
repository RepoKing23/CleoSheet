# CleoSheet — SEO workspace

This repository is the **main folder for all SEO work**: the SEO roadmap sheet and
any related SEO material. Whenever the user asks to update the SEO roadmap or do
other SEO tasks, read from and save to this repo.

## Layout
- `roadmap/` — the SEO roadmap sheet (source of truth) and its change history
- `keyword-research/` — keyword lists, clusters, search-volume exports
- `audits/` — technical / on-page SEO audits
- `content/` — content briefs, outlines, drafts
- `reports/` — performance reports and summaries

## Conventions
- Keep the roadmap as a single canonical file in `roadmap/` (e.g. `seo-roadmap.xlsx`
  or `seo-roadmap.csv`); update it in place rather than creating copies.
- Note notable roadmap changes in `roadmap/CHANGELOG.md` with the date.
- Commit and push changes so nothing is lost between sessions.
